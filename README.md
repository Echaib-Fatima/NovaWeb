# 🚀 NovaWeb

A modern web platform for creating professional websites for small businesses.

## 📌 About the Project

NovaWeb is a full-stack web development project designed to provide professional digital solutions for small businesses.

The platform includes a public website where clients can discover services and submit project requests, as well as a private administration dashboard for managing those requests.

## ✨ Features

### 🌐 Public Website

* Modern and responsive design
* Services presentation
* Portfolio showcase
* Contact form
* WhatsApp integration
* Email contact
* Mobile-friendly interface

### 🔐 Admin Dashboard

* Secure admin login
* Dashboard overview
* Client requests management
* Request details modal
* Client email contact
* Request deletion
* Request status management:

  * 🟣 Nouveau
  * 🔵 En cours
  * 🟢 Terminé
* Request statistics
* Analytics
* Search and refresh functionality
* Admin logout

### 🗄️ Backend

* REST API
* Contact request management
* SQLite database
* CRUD operations
* Persistent request status

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project:

```bash
cd NovaWeb
```

Install backend dependencies:

```bash
cd backend
npm install
```

Start the backend:

```bash
node server.js
```

The backend will run on:

```text
http://localhost:3000
```

Then open the frontend with a local development server such as VS Code Live Server.
